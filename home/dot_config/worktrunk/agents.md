# Worktrunk User Config — Agent Notes

## File structure

- **User config** (`~/.config/worktrunk/config.toml`): Personal hooks that apply to ALL repos. Keep this minimal.
- **Project config** (`.config/wt.toml` in each repo): Project-specific hooks shared with the team.

## Key rules

- **`approved-commands`** is auto-generated by worktrunk's approval flow. Do NOT manually edit it. When a project hook runs for the first time, worktrunk prompts for approval and caches the command here automatically.
- **User hooks run before project hooks.** If a project hook copies `.envrc`, don't put `direnv allow` in user hooks — it'll run too early. Put it in the project's `.config/wt.toml` after the copy step.
- **Hook execution order within a section** follows definition order in the TOML file.

## Typical user config

Only repo-agnostic personal workflows (e.g. `gt track`). Everything project-specific goes in `.config/wt.toml`.
